# AI 厂商活动日报 / AI Deals Daily

给中国用户的全球 AI 免费额度与限时活动日报。

全球厂商的免费活动散在英文官网博客、定价页、社交媒体和社区里，这个仓库每天把它们收集、翻译、核实、按中国用户能不能领排好，发在这里。

## 更新规则

- 采集时段（北京时间）：每天 9:00、14:00、20:30 三段采集。
- 晚间汇总：多日、长期的活动攒到晚上统一发布当日版。
- 今日急报：只限当天的内容，采集到就立即推送，不等晚间汇总。
- 已过期：采集到也不推，只进归档。
- 排序：先放中国用户能直接领的，再放需要海外账号或海外支付的，最后放地区受限或只限特定人群（学生、企业等）的。

## 核实标准

- 官方已核实：进正文。
- 多个独立信源交叉对上、但还没有官方页：进“待确认线索”区，并标清楚风险。
- 只有一个社媒爆料：只内部跟进，不公开发。
- 正式发布前，每条都要回官方页复核一次，额度、截止以官方页为准。
