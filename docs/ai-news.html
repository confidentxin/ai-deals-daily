Thinking Machines 发布开源权重模型 Inkling 2 Mini：26.4B 总参数的 looped transformer，可在笔记本上运行

Thinking Machines Lab 发布开源权重模型 Inkling 2 Mini。官方称它是 looped transformer：中间层对每个 token 循环运行三次，从而在更少参数下做更多推理。官方给出的规模是总参数 26.4B、每 token 激活 3.4B；官方还称，在总参数低于 100B 的开源权重模型中，它在 DeepSWE v1.1（48.2%）和 Vals Index v2.2（46.5%）等基准上领先。模型内存占用约 20GB，可在本地设备运行。
